VPN MANAGER 1.3.19

Изменение версии
Ошибки IKEv2 показаны на русском с исходным кодом Windows.
Сообщение 628 означает разрыв соединения, а не доказанное отсутствие сертификата.
Для ошибок сертификатов даны отдельные пояснения. Сертификаты устанавливает IT;
менеджер не устанавливает их и не изменяет параметры VPN.

Установка
1. Сначала проверьте пакет на отдельном доменном тестовом ПК с WireGuard.
2. Получите пакет из доверенного источника и сверяйте SHA-256 с доверенной
   контрольной суммой. Пакет не подписан; сумма из того же источника сама
   по себе не подтверждает издателя.
3. Перед запуском поместите установщик в папку, где сотрудник не может
   изменять файлы. Запустите его с административными учетными данными IT.
4. Установка фиксирована в Program Files. Выберите общие ярлыки.
5. Проверьте определенного пользователя текущей сессии или укажите его
   вручную как ДОМЕН\пользователь. Для настройки WireGuard выберите
   нужные туннели и подтвердите учетную запись, SID и список.
6. Сотрудник открывает менеджер через ярлык без прав администратора.

Разрешения
На выбранные службы WireGuard сотрудник получает только просмотр состояния,
запуск и остановку (0x34). Он не становится администратором.
Клиент не повышает права, не выдает доступ, не создает и не удаляет службы.
Установщик проверяет защиту штатных конфигов и компонентов WireGuard.
Владелец и DACL файла .conf.dpapi могут читаться через имеющуюся SeBackupPrivilege
в кратковременной копии административного токена. Содержимое и приватные ключи
не читаются; разрешения конфигов и учетных записей не меняются.
Для нового конфига без службы при подготовке возможен краткий запуск туннеля.
Существующие работающие службы не останавливаются.

Обновление и удаление
Менеджер скачивает установщик, но не запускает его. Проверяет и устанавливает IT.
При обновлении выдача прав выключена по умолчанию; имеющиеся права сохраняются.
Для новой или пересозданной службы настройку доступа повторяет IT.
Удаление менеджера не удаляет WireGuard и не отзывает выданные права службы.
Перед повторной установкой после удаления завершите перезагрузку.

Памятка о старой версии
Только если старая копия есть: выйдите через трей, отключите ее автозапуск
и удалите пользовательскую установку из AppData под сотрудником.
Не используйте настройку WireGuard в 1.3.8-1.3.12 и не запускайте эти менеджеры
от администратора. При первой установке удалять ничего не нужно.

Проверки
Автоматические проверки пакета, защиты, интерфейса и русских сообщений пройдены.
Тест rasdial использовал только отсутствующий профиль, без реального подключения.
Повышенные ветки чтения метаданных/регистрации и полный цикл на доменном ПК
еще требуют проверки IT: установка, ярлыки, старт/стоп под сотрудником,
перезагрузка, повторная установка без выдачи прав и удаление.

Пакет распространяется через публичный репозиторий обновлений GitHub.
